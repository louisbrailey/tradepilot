## Backup and runtime boundaries

Private ACL/reparse/hardlink checks protect mutable data; administrator control files reject nonadmin ownership/writes. Suspended Kronos children enter kill-on-close jobs before execution, with credential-free offline environment. Timeout/completion kills descendants. Output >2MB is checked every50ms, permitting sampling overshoot rather than a hard quota. Poisoned inference triggers bounded drain/restart; replacement workers require Ollama idle. Persistent busy inference safely blocks recovery.

An exclusive writer lease excludes another gateway/offline restore. Periodic backups run inside that lease as the gateway identity. First attempt60s, then hourly;10GiB retained-backup threshold and5GiB free reserve checked during copy. SQLite images are consistent per DB, not atomically across the set. Manifest explicitly records whole_set_atomic=false, per-DB timestamps/hashes and is published last after flush/integrity checks. Copy deadline60s per DB plus stop cancellation; partial evidence remains unmarked. No automatic deletion. Failures appear in private/runtime/backup-status.json. Budgets are sampled thresholds, not filesystem quotas. Restore requires fencing, absent activation permit, exclusive lease and a fresh private destination; never swaps/activates it.

C: is the only physical storage. Mac owner can mirror completed manifests/listedfiles over pinned SSH to owner-only storage when awake, verify hashes and unchanged source manifest, and publish destination completion last. No backup HTTP endpoint or PC dependency on Mac availability. Partial transfers stay separate; no automatic evidence pruning. Actual periodic/off-host restore acceptance remains required.

Offline operational maintenance also uses the same GatewayService virtual identity: Prepare-ServiceMaintenance.ps1 requires stopped/fenced gateway and no activation/preflight request. It creates an admin-owned nonce request for backup or restore-isolated with an exact completion-manifest hash. The service checks its real SID and fence, takes the exclusive lease and restores only into private/restores/nonce, never private/runtime. It writes a sanitized private/maintenance/nonce receipt and stops. The owner explicitly runs the service for maintenance and removes the preserved request after review. Conflicting control modes fail closed. This avoids an external administrator pretending to satisfy gateway-SID private ACL checks.
